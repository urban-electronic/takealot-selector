# PR #103 — Windows 实测记录模板（方案 B）

本文件是**记录模板与执行说明**，不是实测结果。原因是当前开发环境无法访问 Takealot 站点、
也没有已登录的持久会话，跑不出真实轮次。按 Codex 要求「不为验收造成功」，这里不提供
任何推测或占位数字。

**本模板需在已登录的目标 Windows 机器上执行**，执行人填完后把结果发回，由我脱敏归档。

## 0. 前置约束（违反即作废）
- 使用**现有已安装的 GUI 与采集器**，不安装新工具、不重装、不改运行时。
- **不开真实调价**，不修改任何售价。
- **不重复请求已确认被拦截（challenge/403）的商品页**；采集器已实现首次确认即暂停。
- 不导出 Cookie、凭据、DPAPI 材料、浏览器档案内容。

## 1. 执行方式
1. 双击 `start.cmd`（或 `launcher.py`）启动采集器 GUI。
2. 点「常态采集」，让其完整跑完**至少一轮**。
3. 记录下方字段；日志从 GUI 日志区复制，或取 `%LOCALAPPDATA%\TakealotCollector\` 下的日志。

## 3. 脱敏规则（归档前执行）
- 删除：Cookie、Authorization 头、API Key、URL 查询串、`service-key.dpapi` 内容、档案路径中的用户名。
- 保留：PLID、SKU、错误分类、HTTP 状态码、计数、时间戳。
