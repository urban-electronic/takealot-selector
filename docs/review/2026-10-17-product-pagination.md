# 产品列表翻页位置修复

基线b39e8ba，用户实际反馈：下一页后仍在列表最底部，必须手动向上滑。
原因：客户端仅切片更新页码，受限高度的.product-table-scroll仍保留上一页scrollTop。

修复：仅在用户实际翻页/改变每页数量时，在新页提交后的layout effect将表格纵向滚动归零，并将页面定位到表格顶部（扣除当前导航高度）；保留横向列位置。初次进入、数据刷新、同页跳转不主动滚动，不修改筛选、SKU勾选或业务数据。

运行验证：挂载真实ProductList与MemoryRouter，65条隔离商品。下一页/上一页/首页/尾页/跳转按钮/Enter/50条每页均验证新页首行和scrollTop=0；横向120保持、勾选SKU1保留、搜索test保留、初次及同页跳转不滚动。npm run test:products与build通过。测试为JSDOM实际React组件交互，不是已认证生产窗口验收。

线上检查：当前业务浏览器实际显示“无效或缺失 API Key”，不能把空列表当数据。用户另要求SKU9902416416912中文品名全库排查，已向WorkBuddy交接只读核查；未获认证前未声称已读到或修正实际品名。没有改价、触发采集或生产记账。代码提交、部署及业务验收分别记录于PR。
