# Takealot 网页采集助手

解压后在 Chrome 或 Edge 扩展管理中开启开发者模式，加载本目录（目录内须有 manifest.json），刷新选品系统网页。保持 Takealot 在同一个浏览器中登录并设置南非配送地址。

系统网页打开时，助手会自动读取本店有库存SKU的到期行情任务；正常目标周期为5分钟，大批商品需要排队。网页有“暂停网页采集”按钮，关闭全部系统网页后停止本机采集。已设置的后台常态采集和自动调价开关不受此按钮影响。

助手在当前浏览器打开商品标签页，不导出登录Cookie。验证页面会保留并切到前台，需本人处理；无法保证当前电脑IP永远不遇到网站验证。无需安装Python或运行原桌面程序。

仅允许访问固定系统网页、Takealot商品网站和固定后端。服务访问密钥只放在浏览器会话存储，采集器仅调用行情接口，不调用改价接口。仍需在网站设置中填写服务访问密钥。扩展代码可以在本目录逐项核对。

读取逻辑沿用原程序的严格Buybox卡选择器、连续读取报价一致性检查、配送状态及规格核对。规格有歧义、无报价卡或遇到验证时回报失败，不用推荐商品或广告价格冒充行情。浏览器扩展版本尚未在用户的Chrome/Edge及真实商品页完成端到端验证，不等于原Python采集器的每个后备路径均已复现。

版本1.0.2为受认证采集请求增加固定客户端标识，使网页扩展的90秒连接状态不再干扰原PricePilot本机采集器的15分钟断连租期；继续保留1.0.1的逐商品采集时间保护。已安装旧版时，用新下载包替换原目录并在扩展管理点击重新加载。登录态保存在浏览器，助手不会读取或导出Cookie。
